# CodeOrbitTech Internship Projects

## About
This repository contains three projects completed during my CodeOrbitTech internship.

## Projects
1. **Task 1: Data Cleaning using Pandas** — Cleaning and preparing data using Python and Pandas.
2. **Task 2: Exploratory Data Analysis (EDA)** — Exploring datasets to identify patterns, trends, and insights.
3. **Task 3: Simple Linear Regression Model** — Building and evaluating a regression model using Scikit-learn and Matplotlib.

## Technologies Used
- Python
- Google Colab
- Pandas
- Scikit-learn
- Matplotlib

## Setup Instructions
1. Download the required `.ipynb` notebook from this repository.
2. Open Google Colab.
3. Select File → Upload notebook.
4. Upload the notebook and run the code cells in order.
